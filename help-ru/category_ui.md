## Категория: ui

---
объекты графического интерфейса пользователя


[**ui.aview**](ui.aview.html): отображение массива с курсором и выбором диапазона 

[**ui.bang**](ui.bang.html): кнопка отправляющая пустое событие (bang) <br>
_псевдонимы:_ \[ui.b\]


[**ui.button**](ui.button.html): виджет кнопки c двумя состояниями <br>
_псевдонимы:_ \[ui.btn\]


[**ui.canvas**](ui.canvas.html): холст для рисования <br>
_псевдонимы:_ \[ui.cnv\]


[**ui.cmeter~**](ui.cmeter~.html): многоканальный круговой измеритель уровня сигнала <br>
_псевдонимы:_ \[ui.cm~\], \[hoa.2d.meter~\]


[**ui.colorpanel**](ui.colorpanel.html): виджет выбора цвета 

[**ui.display**](ui.display.html): виджет дисплей <br>
_псевдонимы:_ \[ui.d\], \[ui.dt\]


[**ui.dsp~**](ui.dsp~.html): виджет для включения или выключения обработки звука 

[**ui.env**](ui.env.html): редактор огибающей 

[**ui.filter**](ui.filter.html): виджет-калькулятор коэффициентов для фильтра \[flt.biquad~\] 

[**ui.filter~**](ui.filter~.html): виджет звукового фильтра 

[**ui.gain2~**](ui.gain2~.html): контроль громкости стерео <br>
_псевдонимы:_ \[ui.hgain2~\], \[ui.vgain2~\]


[**ui.gain~**](ui.gain~.html): контроль громкости <br>
_псевдонимы:_ \[ui.hgain~\], \[ui.vgain~\]


[**ui.icon**](ui.icon.html): простая иконка с возможностями нажатия 

[**ui.incdec**](ui.incdec.html): виджет увеличения или уменьшения значения 

[**ui.keyboard**](ui.keyboard.html): виджет клавиатуры <br>
_псевдонимы:_ \[ui.hk\], \[ui.vkeyboard\], \[ui.vk\]


[**ui.knob**](ui.knob.html): виджет ручки <br>
_псевдонимы:_ \[ui.k\]


[**ui.label**](ui.label.html): простой виджет надписи 

[**ui.lcd**](ui.lcd.html): черно-белый растровый дисплей 

[**ui.link**](ui.link.html): виджет гиперссылки 

[**ui.matrix**](ui.matrix.html): матрица переключателей 

[**ui.menu**](ui.menu.html): выпадающее меню 

[**ui.meter~**](ui.meter~.html): пиковый и RMS уровень сигнала <br>
_псевдонимы:_ \[ui.m~\], \[ui.hm~\], \[ui.vm~\]


[**ui.midi**](ui.midi.html): окно просмотра MIDI сообщений 

[**ui.mouse_filter**](ui.mouse_filter.html): фильтр событий мыши из ui объектов <br>
_псевдонимы:_ \[ui.mf\]


[**ui.mouse_route**](ui.mouse_route.html): маршрутизация событий мыши от ui объектов <br>
_псевдонимы:_ \[ui.mr\]


[**ui.number**](ui.number.html): числовой бокс <br>
_псевдонимы:_ \[ui.n\]


[**ui.number~**](ui.number~.html): просмотр числовых значений сигнала <br>
_псевдонимы:_ \[ui.n~\]


[**ui.plot~**](ui.plot~.html): построитель графика для сигналов 

[**ui.polar**](ui.polar.html): 2D слайдер в полярных координатах 

[**ui.preset**](ui.preset.html): менеджер пресетов 

[**ui.radio**](ui.radio.html): радиопереключатель с возможностью множественного выбора <br>
_псевдонимы:_ \[ui.radio*\], \[ui.hrd\], \[ui.hrd*\], \[ui.vrd\], \[ui.vrd*\]


[**ui.rslider**](ui.rslider.html): двухдиапазонный слайдер <br>
_псевдонимы:_ \[ui.rsl\]


[**ui.scope~**](ui.scope~.html): виджет просмотра формы волны 

[**ui.slider**](ui.slider.html): виджет слайдера (ползунка) <br>
_псевдонимы:_ \[ui.hsl\], \[ui.vsl\]


[**ui.slider2d**](ui.slider2d.html): 2D виджет слайдера <br>
_псевдонимы:_ \[ui.s2d\]


[**ui.sliders**](ui.sliders.html): виджет многоползункового слайдера <br>
_псевдонимы:_ \[ui.vsliders\]


[**ui.spectroscope~**](ui.spectroscope~.html): виджет просмотрщика спектра <br>
_псевдонимы:_ \[ui.ssc~\]


[**ui.tab**](ui.tab.html): список текстовых кнопок или текстовых переключателей 

[**ui.toggle**](ui.toggle.html): cовременный виджет переключателя <br>
_псевдонимы:_ \[ui.t\]
