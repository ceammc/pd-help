# route.data

###### separate any messages from bangs, floats, symbols and lists

*доступно с версии:* 0.9.6

---




[![example](../examples/img/route.data.jpg)](../examples/pd/route.data.pd)



## аргументы:

* **TYPE**
routed data type name (optional)<br>
_тип:_ symbol<br>





## свойства:

* **@type** (initonly)
Запросить/установить routed data type name<br>
_тип:_ symbol<br>



## входы:

* data to *first* outlet<br>
_тип:_ control



## выходы:

* data output<br>
_тип:_ control
* other messages<br>
_тип:_ control
