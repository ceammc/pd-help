# system.info

###### retrieve system information: CPU and temperature

*доступно с версии:* 0.9.8

---




[![example](../examples/img/system.info.jpg)](../examples/pd/system.info.pd)





## методы:

* **temp**
request system temperature information. Output in format: temp SENSOR_NAME
VALUE<br>

* **cpu**
request information about system cpus<br>






## входы:

* control input<br>
_тип:_ control



## выходы:

* output [temp SENSOR_NAME VALUE( or [cpu INFO_DICT(<br>
_тип:_ control
